# Motors – موقع معرض سيارات

موقع إلكتروني حديث ومتجاوب لمعرض سيارات، تم تطويره كمشروع لصالح أحد العملاء. يوفر الموقع تجربة تصفح احترافية للزوار، حيث يتيح لهم استعراض السيارات المتاحة، والاطلاع على تفاصيل كل سيارة، وتصفية النتائج حسب احتياجاتهم، والتواصل مع المعرض بسهولة.

## نظرة عامة على المشروع

Motors هو موقع إلكتروني لمعرض سيارات باللغة العربية، يعتمد على تصميم يدعم اتجاه الكتابة من اليمين إلى اليسار (RTL)، ويتميز بتصميم عصري وبسيط يجمع بين الألوان الأسود والذهبي والأبيض.

يركز المشروع على تقديم واجهة جذابة، وتنقل سلس بين أقسام الموقع، وتجربة استخدام سهلة ومريحة على مختلف أحجام الشاشات والأجهزة.

## المميزات

- **التصميم المتجاوب (Responsive Design):** متوافق مع أجهزة الكمبيوتر والأجهزة اللوحية والهواتف المحمولة.
- **دعم اللغة العربية (RTL):** تصميم مخصص للمستخدمين الناطقين باللغة العربية.
- **قسم رئيسي عصري (Hero Section):** يحتوي على أزرار واضحة لتسهيل وصول الزوار إلى أهم أقسام الموقع.
- **عرض السيارات:** عرض السيارات المتاحة مع الصور والمواصفات والأسعار.
- **نظام تصفية السيارات:** يتيح للزوار تصفية السيارات حسب الماركة والفئة والسعر.
- **معلومات عن المعرض:** قسم مخصص لعرض مميزات المعرض والخدمات التي يقدمها.
- **آراء العملاء:** عرض تقييمات وتجارب العملاء.
- **نموذج التواصل:** يتيح للزوار إرسال استفساراتهم بسهولة.
- **التكامل مع WhatsApp:** يوفر وسيلة مباشرة للتواصل مع المعرض.
- **أساسيات تحسين محركات البحث (SEO):** يتضمن بيانات وصفية مناسبة لتحسين ظهور الموقع في محركات البحث.

## التقنيات المستخدمة

- CSS3
- JavaScript (Vanilla JS)
- Google Fonts – Cairo

## كيفية تشغيل المشروع

1. قم بتحميل المشروع أو عمل Clone للمستودع.
2. افتح مجلد المشروع.
3. افتح ملف `index.html` باستخدام أي متصفح ويب.

لا يحتاج المشروع إلى تثبيت أي أدوات إضافية أو إعداد بيئة تشغيل خاصة.

## تخصيص الموقع

يمكن تعديل محتوى الموقع وتحديثه من خلال:

- تحديث بيانات السيارات والصور والمواصفات والأسعار.
- تغيير معلومات التواصل الخاصة بالمعرض.
- تحديث رقم WhatsApp المستخدم للتواصل.
- تعديل الألوان والخطوط والتنسيقات من خلال ملف `style.css`.
- تعديل محتوى صفحات الموقع من خلال ملف `index.html`.

## تسليم المشروع

تم تطوير هذا الموقع كمشروع لصالح أحد العملاء، مع التركيز على تقديم تصميم احترافي، وتجربة استخدام سهلة، وتوافق كامل مع مختلف الأجهزة والشاشات، بالإضافة إلى توفير وسيلة سلسة لاستعراض السيارات والتواصل مع المعرض.
