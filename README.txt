# موتورز — صفحة هبوط لمعرض سيارات

## التشغيل
افتح `index.html` في المتصفح. لا تحتاج إلى تثبيت أي مكتبات أو تشغيل خادم.

## تخصيص صور السيارات
1. أنشئ مجلدًا باسم `images` بجانب الملفات.
2. ضع صور السيارات داخله.
3. افتح `script.js` وعدّل قيمة `image` لكل سيارة، مثل:
   `image: "images/mercedes-c-class.jpg"`

إذا تركت `image` فارغة، ستظهر مساحة placeholder بدل الصورة.

## إعداد واتساب
في أعلى `script.js` غيّر:
`const WHATSAPP_NUMBER = "201000000000";`
إلى رقم الشركة بصيغة دولية بدون + أو مسافات. مثال مصر: `2010XXXXXXXX`.

## تعديل بيانات السيارات
قائمة السيارات موجودة في بداية `script.js`. يمكنك تغيير الاسم والماركة والفئة والسنة والمواصفات والسعر.

## ملاحظات قبل النشر
- الأسعار والبيانات الحالية تجريبية ويجب استبدالها بالبيانات الحقيقية.
- صور الـ Hero تستخدم صورة خارجية من Unsplash؛ يمكنك استبدال رابطها في `style.css`.
- نموذج التواصل يفتح واتساب برسالة جاهزة ولا يخزن الطلبات في قاعدة بيانات.
